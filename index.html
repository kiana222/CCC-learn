第 0 步 · 学会使用 C++ 编译器

你已有的 C 编译器工具包如果包含 g++，通常就能编译 C++。代码保存为 .cpp；编辑器负责写代码，编译器负责生成程序。先在新终端运行 g++ --version。

先写一个能运行的程序

#include <iostream>
int main() {
    std::cout << "Hello, C++!\n";
    return 0;
}

保存为 hello.cpp，在它所在的文件夹打开终端，编译后再运行：

g++ -std=c++17 -Wall -Wextra hello.cpp -o hello.exe
.\hello.exe

w64devkit 的 shell 中运行命令写作 ./hello.exe。每次修改源码后都要重新编译；运行旧 exe 不会执行新代码。

已有 C 工具包怎么用

本机原 C 学习环境的 E:\C\w64devkit\bin\g++.exe 可用于编译 C++。若终端找不到 g++，可在 PowerShell 调用完整路径；这不会改动你现有的 PATH：

& "E:\C\w64devkit\bin\g++.exe" -std=c++17 -Wall -Wextra hello.cpp -o hello.exe
.\hello.exe

这个路径只适用于存在该工具的电脑。GitHub 页面不包含本机编译器，不需要为了阅读本站下载依赖。

在 VS Code 中练习

  1. 打开保存 .cpp 的练习文件夹，编辑后保存。
  2. 打开集成终端，运行上面的 g++ 命令。
  3. 读取第一条 error: 的文件名与行号，修正后重新编译。编译失败时不要把上次的 exe 运行结果当作新结果。

电脑练习与 STM32 固件

本网站示例按 C++17 编译；标准选择由 -std=c++17 指定。真正的固件需要 ARM 工具链、芯片工程、启动配置和具体板卡驱动。异常、RTTI、动态分配是否允许，应由工程配置与资源预算决定。

自测：把 .c 改名为 .cpp，是否就学会了 C++？

没有。还需要理解 C++ 的类型、对象生命周期、资源所有权和标准库用法，部分 C 写法在 C++ 中也不合法。

补充资料：GCC 的 C++ 标准支持、C++ 工作草案（含较新标准内容）、Arm CMSIS 核心寄存器访问。本站学习与练习以 C++17 为基准。
